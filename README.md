# Suraj Narayan Khot - Portfolio

Responsive single-page PHP Laravel & WordPress Developer portfolio.

## Files

- `index.html` - page structure/content
- `style.css` - responsive styling
- `script.js` - mobile menu, FAQ, animations, navigation, back-to-top

## Run locally

Simply open `index.html` in a browser.

For a local server, use VS Code Live Server or:

```bash
python -m http.server
```

## GitHub Pages

1. Create a GitHub repository, for example `portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for deployment.
7. Your website will be available at:
   `https://YOUR-USERNAME.github.io/portfolio/`

## Before publishing

Replace:
- LinkedIn `href="#"` with your real LinkedIn URL.
- GitHub `href="#"` with your real GitHub URL.
- Demo project cards with your actual project screenshots/links.
- Any project descriptions that do not match your actual work.

No backend is required for this portfolio.
